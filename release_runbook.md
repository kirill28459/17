# Краткий регламент выпуска 1.5.0-rc1 (учебный)

Регламент описывает порядок, реальный выпуск не выполняется.

## Роли
Решение о продолжении и возврате принимает release_owner (teacher_release). Приемку подтверждает acceptance_owner (teacher_process). Исполняет student_engineer, проверки ведет student_tester, пользователей информирует student_support.

## Предварительные условия (все обязательны до 18:00)
1. Решение release_decision.md пересмотрено в пользу «продолжать».
2. T04 passed: восстановление B-1755 в цель, RTO ≤ 20 мин, RPO ≤ 15 мин, данные = контрольному набору.
3. T05 passed: успех ≥ 99 %, p95 ≤ 800 мс.
4. Хеш реального пакета вычислен и записан в паспорт.
5. Среда: Linux x64, Python 3.11/3.12, PostgreSQL 15/16, свободно ≥ 2048 МиБ.
6. Параметры APP_PORT, DB_HOST, DB_NAME, ATTACHMENTS_DIR заданы; секреты переданы разрешенным механизмом.
7. Флаг `category_required` выключен.
8. Опубликовано руководство 1.5.0.
9. Свежая резервная копия, время создания записано (для RPO).

## Контрольная точка возврата
Окно 18:00–18:30, возврат 8 минут: 18:30 − 8 мин = **18:22**.
Если к 18:22 не завершены проверки ниже, release_owner даёт команду вернуть версию. Запись не открывается.

## Контрольные точки
| Время | Действие |
|---|---|
| 18:00 | старт окна, проверка условий 1–9 |
| 18:00–18:15 | миграция M015 (проверить журнал миграций; повтор только после проверки факта) и запуск 1.5.0 |
| до 18:22 | проверки до открытия записи: приложение отвечает, создание и чтение заявки, чужая заявка недоступна, повтор запроса не создает дубль, вложения ≤ 3 |
| 18:22 | решение release_owner: открыть запись или вернуть |
| 18:30 | конец окна |

## Остановка и возврат
Остановка: любой провал проверок, дефект доступа, потеря данных или дубль. Возврат до открытия записи (S1/1.4.2, 8 мин) выполняет student_engineer по команде release_owner. Приложение 1.4.2 читает S2 до включения `category_required`.

## После открытия записи
Если совместимость данных неизвестна (включена `category_required`, появились новые записи), **автоматическое восстановление старой копии не выполняется**: оно удалит новые записи. Требуется новый план согласованного преобразования данных, утвержденный release_owner.
